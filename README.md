# MarketGrid

A modern e-commerce web application built using React.js that provides users with a seamless online shopping experience. The application allows users to browse products, apply filters, manage a shopping cart, and complete a simulated checkout process through a responsive and user-friendly interface.

## Features

* Product browsing through a responsive grid layout
* Product search functionality
* Category-based filtering
* Color-based filtering
* Price range filtering
* Product sorting (Relevance, Price, Rating, Newest)
* Product variant selection (Size & Color)
* Sliding shopping cart drawer
* Quantity management
* Coupon code system
* Checkout page with multiple payment options
* Order summary calculations
* Order confirmation page
* Responsive design for different screen sizes
* Performance optimization using React Hooks

## Technology Stack

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3
* React Router DOM
* Context API
* React Hooks (useState, useEffect, useMemo)
* DummyJSON API
* Vite

## Installation and Setup

1. Clone the repository

```bash
git clone <your-github-repository-url>
```

2. Navigate to the project folder

```bash
cd marketgrid
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

5. Open the application in your browser

```text
http://localhost:5173
```
